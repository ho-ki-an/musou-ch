# 無窓居室判定ツール

建築基準法上の「無窓居室」を室ごとに簡易判定し、あわせて係る規制(非常用照明・換気設備・排煙設備・主要構造部・内装制限・歩行距離)を一覧表示するブラウザ用ツールです。`index.html` 1ファイルで動作します(サーバー不要)。

## 使い方

1. `index.html` をブラウザで開く(GitHub Pagesで公開した場合はそのURL)
2. 「+ 室を追加」で行を増やし、室名・床面積・居室/非居室を入力する
3. 判定方法を選ぶ
   - **A 有効面積を入力**:採光・換気・排煙の有効面積を入力すると、床面積に対する割合を計算して判定する
   - **B 必要面積から判定**:床面積から必要面積を算定して表示するので、確保できるかをYes/Noで選ぶ
4. 無窓に該当する項目に応じて、右側の「係る規制」欄に丸印と対応内容が表示される

## 判定基準

| 項目 | 床面積に対する割合 |
|---|---|
| 採光 | 1/20 |
| 換気 | 1/20 |
| 排煙 | 1/50 |
| 35条の3(令111条) | 1/20(採光有効面積。避難上有効な開口があれば無窓としない) |
| 内装制限 | 1/50 |

## その他の機能

- 行のドラッグによる並べ替え
- 入力済みの行へのチェック、入力枠の右クリックによるグレー表示
- JSONでの保存・読込
- 印刷
- 入力内容はブラウザに自動保存(サーバーには送信されません)

## 注意

簡易判定です。用途・規模・構造による適用除外や緩和(令116条の2、令126条の2、令128条の3の2 等)は、個別に法令で確認してください。
